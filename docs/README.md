# LinkForty Core reference

Reference for running and embedding Core. These pages live with the code, so the copy in a release's git tag matches that release. For guides, see [docs.linkforty.com](https://docs.linkforty.com).

- [API](api.md): links, templates, analytics, QR codes, webhooks, SDK endpoints, health and debug routes
- [Redirects](redirects.md): how a request is routed, the not-found page, the mobile interstitial and the Launchpad page
- [Configuration](configuration.md): server options and hooks, `linkforty.config.json`, reverse proxies, email scanner detection and environment variables
- [Database schema](database-schema.md): tables, and how short codes resolve
- [Using Core as a library](library-usage.md): utilities, custom routes, individual route handlers and starting while the database is busy
- [Export and import](export-import.md): moving data between servers with a bundle
